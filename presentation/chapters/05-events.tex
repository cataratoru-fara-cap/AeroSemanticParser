  \begin{itemize}
    \item kym\_events: one LLM call per Origin/Spread section (ministral-3:14b on the lab's Ollama),
      JSON output constrained by a schema, validated before it is written.
    \item The coverage problem: measured on the full run, 15.3\% of all sentences ended up in no
      event --- the model skipped background and reception. Extraction 4.0.0 (prompt 9) makes it
      an invariant: each sentence starts an event or continues the previous one, and an audit
      refuses a record with a sentence left out. 84.9\% $\to$ 100\% on the review sections, and
      83.6\% $\to$ 100\% on a holdout that was never used for tuning.
    \item Page order is not time order: KYM tells flashbacks on purpose (30 of 753 dated neighbours
      step back in time). The chain (mk:nextInStory) follows the page; the dates carry the time.
    \item Model: SEM's what/when/where/who and EventKG's traceability, aligned in the ontology, not
      copied (no per-statement named graphs). Events are the first nodes MemeAtlas mints from a
      model's reading --- that made it a major version (6.0.0).
  \end{itemize}}
